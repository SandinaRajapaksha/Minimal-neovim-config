# nvim-exp — minimal Neovim config

Leader is `<Space>`. Managed with [lazy.nvim](https://github.com/folke/lazy.nvim). Colorscheme: `cyberdream`.

## Plugins

- blink.cmp
- conform.nvim
- cyberdream.nvim
- flash.nvim
- gitsigns.nvim
- lualine.nvim
- mason.nvim
- mini.nvim
- neogit
- smart-splits.nvim
- telescope.nvim
- toggleterm.nvim
- treesitter
- which-key.nvim

## Requirements

- Neovim >= 0.11
- `git`, `ripgrep`, a Nerd Font

## Install

```sh
git clone git@github.com:SandinaRajapaksha/Minimal-neovim-config.git ~/.config/nvim
nvim
```
